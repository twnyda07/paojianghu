# 跑江湖 · 禪師星球大冒險 🪷

寶嚴禪寺出品 — 給**小朋友**的禪宗公案互動小遊戲。

明亮溫暖的宇宙奇幻 × 紀念碑谷可愛風，沿著一條「光之路」拜訪 **17 位禪宗高僧**，每一站都有一個有趣的公案謎題：先看題目，點一下才翻開故事與答案，再挑戰一題就能收集一顆智慧之星 ⭐。集滿 17 顆，就成為「江湖小俠客」，看見禪宗「一花開五葉」的五大家族！

## 特色
- ☀️ 明亮粉彩、漂浮島嶼、流星與光之路，畫面活潑可愛
- 📍 依祖師與公案發生的**地點**呈現（北方／江南／湖湘／江西／嶺南）
- 🤔 **只露題目，點選才出現答案**，引導孩子先思考
- 💡 偷偷置入輕量知識與令人印象深刻的小故事
- 🌸 五家齊全：臨濟宗・溈仰宗・曹洞宗・雲門宗・法眼宗
- 📜 每則故事皆附《禪宗法脈》原典出處（供師長參考）
- 📱 純前端、可離線、平板手機皆可遊玩；進度自動保存
